Tester le jeu

L'aperçu ouvre le vrai jeu avec toutes les cases ouvertes (énigmes, astuces du week-end et verdict), pour que tu puisses l'essayer comme un joueur.

  • Rien n'est enregistré dans la base : les vrais participants, les équipes et les points ne bougent pas.
  • Tes réponses restent dans ton navigateur. Le bouton « Recommencer » de l'aperçu remet tout à zéro.
  • Les énigmes utilisent les textes et réponses actuels : modifie-les dans l'onglet Énigmes, puis relance l'aperçu pour vérifier.
